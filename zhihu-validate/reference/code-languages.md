# 代码块支持语言

代码块通过 `<pre lang="语言ID">` 指定语言。`lang` 使用下表中的 **id**，不是显示名。

未指定语言时写 `<pre lang="">`。

部分语言支持别名（不区分大小写），导入时也可识别。带别名的语言在「别名」列标出。

共 **345** 种。

## 不支持的语言

以下类型不在可选列表中，转换时不要使用：

- `jsx`（JSX）
- 复合模板语言（如 `css+php`、`js+erb` 等）
- 部分 ANTLR 变体（如 `antlr-cpp`）
- `raw`
